# Hospitality Dashboard - Power BI Project

This repository contains the Power BI project file for my Hospitality Dashboard.

## 🚀 About This Project

This dashboard analyzes key metrics for the hospitality industry, such as:
* Booking trends and occupancy rates
* Revenue per available room (RevPAR)
* Guest demographics
* Customer satisfaction scores

## 🛠️ Tools Used
* Power BI
* Excel (as the data source)
* DAX for complex calculations
